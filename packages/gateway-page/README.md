# @kition/gateway-page

The editor page that `kition gateway` serves: one workspace file in its kit's own editor, the Kit
AI bridge's window for that file, and the review of the agent's drafts. A host frames this page,
usually behind a same-origin proxy. This module is what such a host imports: the page's addresses
(`gatewayPageAddress`) and the types of the `postMessage` protocol it speaks with the window that
frames it. The page itself is built into the `kition` binary. An ES module with type declarations.

```sh
npm i @kition/gateway-page
```

```ts
import { gatewayPageAddress, isGatewayPageMessage, type GatewayPageCommand } from '@kition/gateway-page'

// A same-origin proxy serves the gateway under /kition/.
frame.src = gatewayPageAddress('/kition/', 'notes/Plan.md', { theme: 'dark', locale: 'en' })
window.addEventListener('message', (event) => {
  if (event.source !== frame.contentWindow || !isGatewayPageMessage(event.data)) return
  if (event.data.type === 'state') setTabTitle(event.data.title, event.data.dirty)
})
const save: GatewayPageCommand = { kitionGatewayPage: 1, type: 'save' }
frame.contentWindow?.postMessage(save, location.origin) // the page answers `saved`
```

Documentation: https://github.com/KitionAI/kition-sdk/blob/main/docs/sdk/gateway-page.md
