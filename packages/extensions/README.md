# @kition/extensions

The Kition extension host: add commands and panels to kit editors. An
extension is an `extension.json` manifest and one ES module. The host runs each extension in a
sandboxed worker on an opaque origin that reaches only the network origins it declares. It serves
the extension the object model (`@kition/script`) of the documents it is active on, checked against
its permissions. An ES module with type declarations, for the browser.

```sh
npm i @kition/extensions
```

```ts
import { ExtensionHost, iframeSandbox } from '@kition/extensions'
import { portFromConnection } from '@kition/script'

const host = new ExtensionHost({
  sandbox: iframeSandbox({ url: '/extensions/sandbox.html' }),
  notify: ({ level, title, description }) => toast(level, title, description),
})
host.load({ manifest: manifestText, source: entrySource })
host.openDocument({ id: path, kitId: 'kit.note', path, port: portFromConnection(connection) })
host.commandsFor(path) // for a palette or a menu
await host.runCommand(path, 'com.example.title-case', 'titleCase.apply')
```

- `@kition/extensions/runtime`: the extension's side, with the types of `activate(ctx)` (`ExtensionContext`).
- `@kition/extensions/sandbox.html` and `@kition/extensions/panel.html`: the sandbox and panel pages to serve as static files.

Documentation: https://github.com/KitionAI/kition-sdk/blob/main/docs/platform/reference/extensions.md

## Part of the Kition SDK

`@kition/extensions` is a package of the [Kition SDK](https://github.com/KitionAI/kition-sdk) ([its source](https://github.com/KitionAI/kition-sdk/tree/main/packages/extensions)), which lets you put Kition's editors in your product, and give the same files to your AI agent. Guides and reference: [developer.kition.ai](https://developer.kition.ai).
